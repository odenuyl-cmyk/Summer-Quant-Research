# Quantitative Research: Optimal Trade Execution

This repository contains my personal code for researching and simulating optimal trade execution using limit order book data. The research writeup documents the full research process, methodology, and results. Some code is omitted due to collaboration and is not included in this repository.

## Files

- `analysis/` — Market imbalance and market-order analysis.
- `simulation/` — Monte Carlo execution simulations (`MC_Simple.py`, `MC_Full.py`).
- `Initial_Model.py` / `Initial_Model.ipynb` — Initial model development.
- `Research_Writeup.pdf` — **Complete research methodology, results, and conclusions.**

Download and view `Research_Writeup.pdf` for all substantive research details.
